ReGrow AI 作业 3｜打开方式

当前状态：
本项目目前没有部署到云端，也没有正在对外提供访问的 FastAPI 服务。
http://127.0.0.1:8000 只有在当前电脑启动后端以后才能打开，不能把这个链接直接发给别人。

最简单的方式：
直接双击“ReGrow-AI-作业3-双击打开.html”。这个文件不需要安装 Python，不使用 127.0.0.1，断网也能查看界面和演示操作。离线文件使用浏览器内演示数据，不会实际运行 FastAPI、Agno、SQLite 或 SQL 沙盒。

完整后端方式：

1. 解压整个文件夹，不要只单独打开某个 HTML 文件。
2. 电脑需要安装 Python 3.11 或更高版本。
3. 双击“启动作业.bat”。
4. 第一次运行会在线安装 Python 依赖，请保持网络连接。
5. 安装完成后，浏览器会自动打开 http://127.0.0.1:8000。
6. 演示期间不要关闭黑色命令窗口；演示结束后按 Ctrl+C 停止项目。

说明：
127.0.0.1 表示“当前这台电脑”。把压缩包发给别人后，对方运行的是自己电脑里的项目，不会连接作者的电脑。
项目默认使用固定演示数据，不需要填写 OpenAI API Key。

如果收到的是云端链接，直接用浏览器打开即可。云端完整版仍会运行 FastAPI、SQLite、SQL 沙盒、动态工具、护栏和人工审核。
